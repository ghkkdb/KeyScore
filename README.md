# KeyScore 键谱

面向 Windows 游戏乐器的文本简谱自动演奏工具。当前为第一版原型，只向前台游戏窗口发送标准 Windows `SendInput` 键鼠事件。

## 开发环境

```powershell
py -3.10-64 -m venv .venv64
.\.venv64\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:PYTHONPATH = "src"
python main.py
```

## 使用流程

1. 通过左侧歌单选择已有曲谱，或点击“导入”将 `.txt` 曲谱复制到本地曲谱库。
2. 双击曲谱或点击“编辑”，在独立窗口中修改并保存。
3. 如需修改键位，打开“设置”，点击音符或音区按钮后录入键盘/鼠标按键。
4. 切换到游戏的乐器界面。
5. 按 `F9`，无需选择游戏；程序自动记住当时的前台窗口并显示 3 秒倒计时。
6. 播放时再次按 `F9` 暂停或继续，按 `F10` 紧急停止。

如果前台窗口在播放中发生变化，播放器会自动暂停并释放所有已按下的键鼠按键。

## 简谱语法

```text
@title 小星星
@bpm 100
@beat 4/4
@section_gap 2

1 1 5 5 | 6 6 5:2 |
---
8
#1
L1
H5:0.5
0:2
[1 3 5]:2
```

其中 `8` 表示可独立绑定的高音 Do，`#1` 表示按住半音修饰键后演奏 Do，`L1` 表示按住低音修饰键后演奏 Do，`H5:0.5` 表示按住高音修饰键后演奏 Sol 并占用半拍。普通的 `1～8` 默认为中音，不发送任何音区修饰键。独立一行的 `---` 表示段落停顿，拍数由 `@section_gap` 设置；没有设置时默认停顿一拍。

### 时间参数

- 音符起点间隔由 BPM 和时值决定：`60000 / BPM × 时值`。
- `0:0.5`、`0`、`0:2` 分别产生半拍、一拍和两拍的精确休止。
- 普通换行、空行和小节线不产生停顿；段落之间应使用 `---`。
- “按键时长”决定一次 KeyDown 到 KeyUp 的最长时间。
- “最小释放间隔”保证在下一个拍点前提前松键，默认 10ms，用于降低连续同键被游戏合并或漏读的概率。

## 测试

核心层只使用 Python 标准库，不安装 GUI 依赖也可运行：

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```

## 安全说明

软件不会读写游戏内存或注入游戏进程，但自动键鼠工具仍可能违反某些游戏的服务条款。请在使用前了解目标游戏的规则。
